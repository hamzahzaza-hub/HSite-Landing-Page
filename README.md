# Hsite — Landing Page & Feedback Hub

> **Building in Public (4-Week Student Project)**  
> Live Landing Page: [https://hamzahzaza-hub.github.io/HSite-Landing-Page/](https://hamzahzaza-hub.github.io/HSite-Landing-Page/)

This repository holds the landing page and student feedback portal for **Hsite**—an upcoming mobile app designed to help university students find study partners, map out degree requirements, evaluate transfer credits, and team up on side projects.

---

## 🌟 App Overview & Planned Features

* 🤝 **Study Partners & Groups:** Connect with peers in your major and form course-specific study groups.
* 🗺️ **Class Planner:** Import your degree audit or transcript to track completed classes and plan future semesters.
* 🔄 **Transfer Credit Plans:** Evaluate transferred courses to see direct equivalencies and degree progress.
* 🎯 **Goal-Based Scheduling:** Align course plans with graduation targets and work schedules.
* 🚀 **Side Project Teams:** Post project ideas or find teammates with specific skills.
* 💬 **Major Chat:** Engage in dedicated discussions with peers in your major.

## 🛠️ Tech Stack

### 📄 Landing Page (This Repository)
* **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6)
* **Hosting:** GitHub Pages
* **Form Submissions:** FormSubmit (AJAX) with fallback email options

### 📱 Mobile App (In Development)
* **Frontend:** React Native + TypeScript (iOS first; Android & Web planned next)
* **Backend & Database:** Supabase (Auth, PostgreSQL, and Real-Time Chat)
